# 다음 업데이트 4 노트 (2026-10-24 15:18 요청)

업데이트 3(PR #25) 위에서 이어 작업합니다. 아래는 요청 정리와 현재 코드에서 확인한 원인, 그리고 진행 전에 정할 것입니다.

## 요청

### 1. 웹폰트를 기존 글꼴 기능에 제대로 합치기

- 증상
  - 설정에서 적용해도 실제 채팅에 반영되지 않는 것 같습니다.
  - 채팅방 읽기 설정의 글꼴 목록에 웹폰트가 나오지 않습니다.
- 코드에서 확인한 원인
  - 읽기 설정의 글꼴 목록(`ReaderSettings` → `useReaderFonts`)은 엔진 글꼴 폴더(`/api/fonts`)만 읽습니다. 웹폰트는 `app-settings`의 `web-fonts`에 따로 저장되어 이 목록에 들어가지 않습니다.
  - 그래서 글꼴 설정이 두 군데로 갈려 있습니다.
    - 읽기 설정: RP·CONVO 공용 글꼴과 글자 크기
    - 웹폰트 패널: UI·RP·CONVO별 글꼴, 크기, 자간, 줄간격(`!important` CSS)
  - 두 설정이 서로를 모르고 겹칩니다. 어느 쪽이 이기는지 화면에서 알 수 없습니다.
- 실제로 적용되지 않는 원인은 아직 확인하지 못했습니다. 샌드박스 E2E에서는 적용됐습니다. 실기기에서 쓴 코드(눈누·구글 폰트 등)를 받아 재현한 뒤 고칩니다.
- 설계 방향(제안)
  - 웹폰트는 "글꼴 등록소"로만 둡니다. 등록한 글꼴은 엔진 글꼴 폴더 글꼴과 같은 목록에 나옵니다.
  - 글꼴 선택은 이미 있는 자리에서 합니다.
    - UI 글꼴: 외관 설정의 기존 글꼴 항목
    - RP·CONVO 글꼴: 읽기 설정(채팅방 보기 설정)의 글꼴 항목
  - 크기·자간·줄간격도 읽기 설정에 둡니다. 따로 덮어쓰는 `!important` 규칙은 없앱니다.
  - 기존에 저장한 웹폰트 대상 설정은 처음 한 번 읽기 설정으로 옮깁니다(데이터 호환).

### 2. RP 모드에서 캐릭터 이름 숨기기

- RP 메시지 머리의 이름(`.mari-message-name`, RP 표면 안)을 CSS로 숨깁니다.
- 아바타, 시간, 메시지 도구는 그대로 둡니다.

### 3. 채팅 설정 › UI 관리 정리, 전역 적용

- 증상(스크린샷)
  - 위치가 "숨김"인 줄은 손잡이와 ↑↓ 버튼이 사라집니다. 그래서 상단·리모콘·설정·숨김 버튼 묶음이 오른쪽으로 밀려 줄마다 열이 어긋납니다.
  - 긴 이름은 "프롬프트 프…"처럼 잘립니다.
- 정리 방향
  - 이름, 위치 선택, 순서 버튼을 고정 열로 맞춥니다.
  - 숨김 줄에도 같은 자리를 비워 둡니다(비활성 표시).
  - 휴대폰 폭에서는 이름을 한 줄 위에 두고, 위치 선택과 순서 버튼을 아래 줄에 둡니다.
- 적용 범위
  - 지금은 모드별(RP 따로, CONVO 따로)로 저장됩니다(`chatUiLayout[mode]`). 방마다 따로 저장되지는 않습니다.
  - 요청대로 모든 채팅에 하나로 적용합니다. 기존 모드별 값은 처음 한 번 합칩니다(아래 질문 2).

### 4. 몰입 모드에서 TTS 재생/재생성 (검토)

- 지금은 몰입 모드에서 메시지 도구와 함께 대사별 TTS 버튼도 숨겨집니다.
- 제안: 대사(따옴표 구간)를 누르면 그 자리에 작은 팝업이 뜨고 재생·재생성 버튼을 보여 줍니다.
- 이렇게 하면 평소에는 대사 옆 버튼을 아예 숨길 수도 있습니다.
- 겹치는 동작
  - 휴대폰에서 메시지를 누르면 메시지 도구가 열리는 동작
  - 글자를 길게 눌러 선택하는 동작(발췌·선택 저장)
- 짧게 누를 때만 팝업을 띄우고, 길게 누르기와 드래그 선택은 지금처럼 둡니다.

### 5. CONVO 버블: 원문과 번역문 사이 거리

- 업데이트 3에서 넣은 간격(위 여백 0.375rem + 줄 위 여백 0.375rem)을 더 좁힙니다.
