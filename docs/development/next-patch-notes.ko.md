## 1. 기준과 작업 순서

기존 기능 보존 > 호환성 > 요청사항 완전 구현 > 검증 > 최적화. 최신 코드를 먼저 확인하고 정상 구현은 재작성하지 않는다. 이번 변경은 개발자 노트 작성이며 앱 코드는 변경하지 않는다.

- 화면 디자인 기준은 사용자가 지정한 원본 목업이다. TTS ZIP은 음성 동작·배치 레퍼런스이며 목업을 대체하지 않는다.
- 홈·채팅목록·대화·설정·팝업의 배경, 글자, 여백, 버튼, 밀도를 목업과 나란히 비교한다. 순정/애드온 테마 변경 후에도 네온·발광·강조색이 유입되지 않아야 한다. 현재의 임의 색상이나 빌드 통과만으로 일치 판정을 하지 않는다.
- 한국어 메뉴·설명·선택지·버튼·오류·접근성 안내를 점검한다. 외부 확장의 영어 화면도 번역 키에 연결한다. 사용자 원문과 모델 식별자는 번역하지 않는다.
- 엔진 선택 글꼴을 따른다. 자간 px·행간 배율 모두 0.1 단위 직접 입력, 증감, 즉시 미리보기, 저장·재접속 복원을 확인한다.
- 모바일 터치 영역, 줄 잘림, 과도한 여백, 키보드 가림, 가로 넘침을 점검한다. 설정 변경으로 스크롤·입력 초안을 초기화하지 않는다.

## 3. 설정과 추가 확장 통합

- 설정 탭은 기능에 직접 접근하는 올인원 마이페이지로 유지한다. 음성 연결/Persona 보이스 설정은 접근 가능하게 하되 방별 RP 옵션을 전역 연결 설정과 혼동시키지 않는다. 실제 경로·저장·오류 복구를 각각 확인한다.
- NAI 캐릭터 프롬프트 v1.3.0, 삽화 버튼, WebP 기본 품질 95, 기존 SharedNAI는 최신 구현을 먼저 확인하고 결함만 수정한다. 구현과 실제 제공자 검증을 구분한다.
- key_save, NovelAI Metadata Importer, global preset, excerpt studio, 번역 프리셋·단어장 1.6.4, 대화 날씨 0.2.1 통합은 여전히 미완료다. 확인한 소스·연결 위치는 extension-integration-map.ko.md를 따른다.
- 기존 생성·편집·재생성·번역·TTS·통화·채팅 삭제·저장 데이터와 기존 URL을 보존한다. 깨진 경로를 버튼만 있는 상태로 남기지 않는다.

## 5. 현재 판정

44d989c까지의 기존 모바일 자동 검사 8개와 빌드 통과는 해당 범위의 증거다. 이번 ZIP을 기준으로 한 전체 기능 동등성·대사 옆 UI 일치·원본 목업 일치·실제 제공자 합성은 검증 완료되지 않았다. 기존의 “대사별 TTS 구현” 보고는 레퍼런스 전체 구현 완료를 의미하지 않도록 정정한다.

이번 작업은 첨부 소스 확인과 개발자 노트 작성만 수행했다. 앱 기능을 수정하거나 새 테스트를 통과했다고 보고하지 않는다. 위 차이를 수정·검증하고 원격 보존하기 전 전체 완료 선언을 하지 않는다.
