# 캐릭터 편집창의 커스텀 접근 경로

2026-10-23 사용자 추가 확정사항: 표지 등 커스텀 항목은 홈이 아니라 각 캐릭터 편집창 안에서 편집한다. 첨부 `Marinara-Frontend-Handoff(1).zip`의 커스텀 영역 요구에 이 접근 경로를 우선 적용한다.

- 기준: PR #13 병합 후 main `acb720f6ff7db45cf779a4bf408a86f896584449`.
- 경로: 캐릭터 편집 → 메타데이터 → **서재 꾸미기**.
- 기존 표지 업로드·2:3 크롭·저장·초기화 UI를 재사용한다. 캐릭터 아바타와 원본 카드는 변경하지 않는다.
- 캐릭터 단독 작품과 해당 캐릭터가 참여한 그룹 작품만 선택할 수 있다. 그룹 표지는 참여 캐릭터들의 편집창에서 같은 저장 키를 사용한다.
- `libraryCovers`와 작품/캐스트 키를 유지하므로 이미 저장한 표지는 이전하지 않아도 표시된다. 홈·작품 상세의 표지 편집 진입점은 제거한다.
- 작품 전환 시 저장 전 표지 변경이 있으면 취소 여부를 확인한다. 펼치기 전에는 커스텀 편집기의 조회·코드를 로드하지 않는다.
- 캐릭터가 없는 기존 작품의 저장된 표지는 표시를 유지한다. 캐릭터 편집창은 존재하지 않으므로 해당 작품에 새 홈 편집 경로를 만들지 않는다.

검증 기록: 로컬라이제이션·포맷 검사 통과. 전체 `pnpm check`와 PC/모바일 브라우저 검사는 진행 중이다. 결과는 후속 커밋에 기록한다.

이 변경은 커스텀 진입 경로를 옮기는 패치다. 인계서의 TTS 표시 오류, 번역/발췌 진입 위치, 제목·별명·설명 커스텀 필드 확장, 문단별 말풍선·번역, 읽기 설정·기록 디자인과 헤더 간격 수정은 이 패치의 완료 범위가 아니다. 원본 요구사항은 유지한다.
