# 확장 통합 중간 체크포인트 — 2026-10-22

사용자 요청에 따라 현재 구현을 우선 중간 커밋으로 보존한다. 이 문서 상단이 최신 상태이며, 아래 이전 체크포인트는 이력이다. 전체 완료·병합 완료를 뜻하지 않는다.

## 현재 코드에 연결한 기능

- 키 보관함: 마스터 비밀번호로 AES-GCM 암호화, 키 이름·그룹 관리, 연결 적용·편집기 초안 선택, 암호 변경·초기화·백업, key_save v1 암호화 백업 가져오기.
- NAI 메타데이터: PNG 텍스트·압축 텍스트·알파 숨김 데이터, WebP 보존 청크·EXIF 파싱. 선택 필드만 연결 편집기 초안에 적용하며 모호한 모델은 선택하도록 한다. 시드 -1·UC 0 정책을 표시한다.
- 전역 프리셋: 전역 따르기·개별 고정·사용 안 함, 기존 방의 명시적 선택 보존, 일괄 적용·변경 이력·설정 충돌 검사. 연결 프리셋 우선순위는 기존 생성 경로를 따른다.
- 번역: 입력·출력 프리셋, 기본값·방별 단어장·말투·세계관·선택 로어북·이전 메시지 참고, AI 용어 추출, 문단별 대조·편집·재번역. 원문·스와이프 확인 후 저장. 코드·음성 태그 보호. 구 확장 백업을 검토 가능한 초안으로 가져오기.
- 날씨: 지역 검색·선택, 유저·캐릭터 지역, Convo 방별 활성화, 15분 캐시·동시 조회 합치기. 모델에는 날씨·기온만 보내며 지역명·좌표는 제외한다. 조회 실패 시 본 생성을 계속한다.
- 발췌: 선택 문장 또는 직접 입력, 형광펜·밑줄·가림·치환, 글꼴·행간·자간·크기·배경, 미리보기·PNG 출력·설정 저장. 출력 픽셀 수를 제한한다.
- TTS: 기존 대사에 React 제어 버튼 연결, 생성·캐시·로딩·재생·정지 상태, 장문 대사 단위 제어, 방·메시지·스와이프·연결별 캐시 구분, Persona 보이스 부분 저장, 방별 버튼·화자 방식·드래그 메뉴. 표시 대사 수와 원문이 맞지 않으면 화자를 추측하지 않고 별도 제어 행을 사용한다.
- 마이페이지에 위 도구 진입 연결 및 한국어 문구 추가. 앞선 Convo 분리·독립 표지·SharedNAI 대기열 수정은 유지한다.

## 이 시점에 통과한 검사

- `native-integrations.regression.ts`: 설정 CAS·기존 프리셋 보존·일괄 적용, 번역 방향·용어 선별, 키 암호화/키 적용/비밀번호 변경/v1 백업 호환·변조 거부, TTS 참여자/보이스/반복 대사/연결별 캐시, 구 설정 가져오기, PNG 텍스트·압축·알파 메타데이터.
- 공유 패키지 빌드 통과.
- 한국어·영문 로컬라이제이션 검사 통과(추가 후 최종 트리 재검사 필요).

## 이번 반영

- NAI 대기열: 재시작 때 완료된 계정까지 일괄 중지하던 원인 수정. 이전 버전이 restart 사유로 중지한 유휴 계정도 복구한다. 중단·결과 불명 작업은 자동 재전송하지 않고 수동 중지·429 제한도 유지한다. 대기열은 삭제하지 않았다.
