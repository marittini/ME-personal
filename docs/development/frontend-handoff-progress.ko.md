# 프론트엔드 인계 항목 구현 및 검증

2026-10-22, PR #14 후속 작업. 원격 main의 PR #13 병합 후 작업이며, 배포·main 병합은 하지 않는다.

## 구현 범위

- TTS: HTML 인코딩된 audio 태그를 표시 전에 인식하고, 굵은 대사와 HTML 대사에 재생 버튼 연결 지점을 부여한다. 원본 메시지·감정 지시·화자 정보와 음성 캐시는 유지한다. 번역 과정에서도 태그를 원형으로 복원한다.
- 번역: 프리셋·단어장을 기존 채팅 설정의 번역 섹션에 넣고, 열린 방을 기본 편집 대상으로 사용한다. 마이페이지의 독립 메뉴는 제거한다.
- 발췌: 본문 선택으로 스튜디오 진입, 대화방 메타데이터에 글·꾸밈 표시·출처 위치 저장, 목록에서 수정·삭제·본문 이동. 재진입 시 정확히 같은 표시 본문에만 강조를 복원한다. 원문·번역·스와이프가 달라지면 다른 구절에 강제로 연결하지 않는다. 본문은 수정하지 않는다.
- 꾸미기: 캐릭터 편집창 내부에서 작품 제목·표시 이름·설명 저장/취소/초기화. 표지와 같은 작품 키를 재사용하고 원본 캐릭터 이름·카드 데이터와 분리한다. 서재·최근 읽기·작품 상세·캐릭터 서재의 표시 우선순위를 일치시킨다. 별도 페르소나 카드의 원본 이름은 그 카드 편집창에서 유지한다.
- 읽기 설정: 기존 글꼴 목록과 등록된 사용자 글꼴, 크기·테마·정렬·줄/문단 간격·문단 들여쓰기를 사용한다. 오래된 설정은 기본값과 범위 검사를 거쳐 복원한다.
- CONVO·그룹: 빈 줄 기준 말풍선 분리, 단일 줄바꿈 유지. 코드·목록·인용 블록 보존. 문단 수가 같은 번역만 순서 대응, 불일치 시 전체 번역 표시. 화자/반응 인덱스와 원본 메시지는 유지한다.
- 읽기 기록: 기존 순서와 이동 기능을 유지하며 번호·제목·마지막 위치의 목차 형태로 바꾼다.
- 레이아웃: 편집창 및 중앙 flex 호스트의 최소 높이를 명시한다. 모바일 상단 정렬은 실제 브라우저에서 별도 확인한다.

## 검증 상태 (중간 커밋)

- 전체 `pnpm check`: 1차 통과. 기존 Hook 경고 5개 및 번들 경고. 이후 브라우저에서 발견한 문단 클래스 중복과 CONVO 위치 번호 누락을 수정했으므로 최종 재검사가 필요하다.
- `reader-handoff.regression.ts`, `room-tts-guidance.regression.ts`: 통과.
- 1차 브라우저: 그룹 문단 번역, 인코딩된 TTS 대사 연결, RP/CONVO 캐시 음성 재생 통과. 일반 CONVO 클래스 중복·발췌 위치 번호 누락을 수정했다. 설정 이동 테스트는 숨겨진 상단 버튼 대신 서재 탐색 버튼을 사용하도록 수정했다.
- PC/모바일 통합 재검사, 최종 타입·빌드, 시각 점검은 진행 중이다. 이 중간 커밋은 전체 완료 판정이 아니다.

## 제한 및 남은 확인

- CSS Custom Highlight API가 없는 구형 브라우저는 본문 강조 표시가 지원되지 않는다. 저장 목록·편집·출처 이동·PNG는 독립적으로 사용한다.
- 캐릭터 없는 방은 기존 표지를 표시하지만 캐릭터 편집창에서 꾸미는 진입점이 없다. 가상의 캐릭터를 생성하거나 홈 편집 경로를 다시 만들지 않았다.
- 실제 iOS Safari·Android/Termux, 모바일 기본 길게 누르기 메뉴/키보드는 실기기 미검증이다.
- 이 포크에서 제거된 게임 시작 UI는 임의로 되살리지 않는다. 과거 게임 설정 취소 관련 재현은 별도 범위로 남긴다.
- CodeRabbit CLI는 실행 환경에 없어 미실행. PR은 Draft를 유지한다.

## 후속 보정

- 표지를 저장하거나 지운 뒤 미저장 상태가 남아 경고가 뜨던 경로를 수정했다. 서재 표시 정보가 미저장 상태라면 캐릭터 편집창 전체를 닫을 때도 확인하며, 취소하면 입력을 보존한다.
- 본문의 기존 인라인 마크다운·TTS 대사 경계를 유지하며 문단 간격·들여쓰기 적용 지점을 추가했다. 코드의 들여쓰기와 끝나지 않은 코드 펜스를 보존한다.
- 순정 FloatingWindow의 상단 장애물 계산에 독서 헤더를 포함했다. 채팅 설정 아이콘이 독서 도구 버튼을 가리던 실제 겹침을 제거한다.
- 최종 `pnpm check` 통과, 추가 E2E 타입 검사 통과, handoff/room-TTS/native-integrations 회귀 통과. 최신 PC·모바일 브라우저 34개 시나리오와 순정 smoke 7개를 실행 중이다.
- 별도 실행한 `floating-window.regression.ts`는 이 포크의 미수정 ChatSettingsDrawer에서 이미 제거된 GameWidgetSetupEditor 존재를 요구하는 검사에서 실패한다. 이번 변경의 창 배치 검사는 실제 브라우저 경로에서 수행한다. 이 실패를 통과로 처리하지 않는다.
