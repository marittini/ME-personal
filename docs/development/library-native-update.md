# 서재 UI / 순정 TTS 업데이트 작업 기록

기준: 2026-10-22. 완료 표시 대신 실제 반영 범위와 남은 검증을 구분한다.

## 이번 변경

- 같은 캐릭터 구성의 방을 한 작품에 모은다. 제목은 캐릭터 이름, 표지는 크롭된 캐릭터 프로필을 우선한다. 그룹 대화는 별도 작품이다.
- 기록 목록은 방 이름을 먼저 표시한다. 기존 열기·이름 변경·삭제에 새 방 만들기를 연결하고, 계속 읽기는 마지막 읽던 방을 우선한다.
- 로컬 프로필에 320px WebP 미리보기를 적용한다. URL의 버전 쿼리를 보존하고 깨진 표지는 텍스트로 대체한다. 원본 파일은 수정하지 않는다.
- 게임 재생·표시·입력 설정, 게임 이미지 크기 설정, 게임 자산 관리 화면, 오버월드 타일팩 관리 화면을 제거한다. 게임 오디오 생성 API는 410을 반환한다.
- 애드온 테마 선택/편집 화면과 앱의 커스텀 CSS 주입 연결을 제거한다. 계절 테마·인사 팝업도 적용하지 않는다. 글꼴·기본 색상·명암 설정과 저장된 테마 데이터는 보존한다.
- ElevenLabs 유사도·스타일·스피커 부스트와 페르소나별 보이스를 순정 설정에 추가한다. 소스/연결별 설정과 오디오 캐시 키에 반영한다.
- 읽기 설정에서 전역 음성 재생과 방별 음성 지침을 각각 저장한다. 빠른 재생 스위치는 다른 설정을 덮어쓰지 않으며, 저장 성공 후 재생을 중지한다.
- RP 화자 태그는 선택적으로 생성한다. 등록된 참여자의 대사만 합성하고 코드 예시·중첩 마크업·미등록 ID는 제외한다. 표시용 변환은 음성 원문과 사용자 메시지를 수정하지 않는다.
- 프로필 미리보기 캐시, 이미지 지연 로딩, 화면 밖 목록 렌더링 생략, 선택 기능의 제한된 런타임 캐시를 사용한다. 서재 묶음 생성의 반복 배열 복사도 제거한다.

## 완료로 간주하면 안 되는 항목

- 게임/오버월드의 모든 내부 파일·공유 서비스·구형 데이터 타입 삭제. RP 및 기존 백업이 참조하는 코드는 남아 있다.
- 첨부 TTS 확장과의 완전한 기능 동등성. 확장의 로컬 설정 자동 이관, 대사별 인라인 조작, 기존 확장과의 중복 실행 방지는 후속 작업이다. 현재는 순정 설정/메시지 음성 메뉴를 사용한다.
- 대규모 목록의 실제 DOM 가상화와 서버 페이지 단위 조회. 현재 최적화는 이미지·레이아웃 비용을 줄이는 단계다.
- 작품/표지 편집, 서가·즐겨찾기·숨김의 영구 저장, 북마크·하이라이트·메모·목차, 서버 읽기 위치 동기화/복원.
- 프라이버시 가림 화면, 고급 읽기 옵션, 독립적인 오프라인 읽기, 실제 모바일 데이터량·메모리·발열 측정.

## 검증 상태

- `library-previews`, `room-tts-guidance`, `tts-voice-assignment-route`, `reader-position`, `tts-cache-clear` 회귀 검사 통과.
- 이 환경은 tsx CLI의 IPC 소켓과 OS 네트워크 인터페이스 조회를 제한한다. 직접 Node 로더로 실행했고, 파일 기반 저장소/라우트 검사에 한해 네트워크 인터페이스 목록을 빈 테스트 값으로 대체했다. 실제 네트워크·유료 음성 합성 검증을 뜻하지 않는다.
- 기존 `tts-source-persistence` 검사는 이미 삭제된 `GameCombatUI.tsx`를 읽는 단계에서 실패한다. 새 음성 설정/화자 파서 검사는 별도 회귀 파일로 추가했다.
- Playwright Chromium 설치는 손상된 다운로드로 실패했다. 화면·키보드·모바일·실제 오디오 재생은 검증 전이다.
- 전체 `pnpm check` 최종 결과는 PR에 기록한다. 브라우저/실제 제공자 검증 전에는 완료 또는 병합 가능으로 표시하지 않는다.

## 다음 검증 순서

1. 실제 WebP 프로필, 기존 PNG 경로에 저장된 WebP, 깨진 파일, 크롭, 명암 모드를 모바일/데스크톱에서 확인한다.
2. 같은 캐릭터의 RP/대화 방, 그룹 방, 새 방 생성, 이름 변경, 삭제 취소/실패 복구, 마지막 위치 복원을 확인한다.
3. 음성 OFF/지침 ON과 그 반대 조합, 소스 전환, 페르소나 변경, 번역/스와이프 후 원문 합성, 캐시 재생/중지를 확인한다.
4. 기존 확장 비활성화 및 설정 이관을 구현한 뒤 확장과 순정 기능이 중복 요청하지 않는지 확인한다.
5. 게임 관련 공유 파일은 RP·백업 참조를 추적한 후 삭제한다. 위 미구현 기능은 저장·복원·오류 처리까지 연결해 별도로 검증한다.
