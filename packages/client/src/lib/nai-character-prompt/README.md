# Native integration source

Core generator, normalization and prompt rules from leuy5674/marinara-nai-character-prompt v1.3.0, commit e0dee0ffa13ec25b1534abf781b85219c3dc4306.

Source: https://github.com/leuy5674/marinara-nai-character-prompt/releases/tag/v1.3.0

The three JavaScript modules are retained without changing their prompt rules. The native hook supplies the host API client; the React view uses host theme tokens and localization. No floating launcher, DOM observer, global fetch patch or card mutation is installed. LICENSE and THIRD_PARTY_NOTICES.md retain the upstream MIT notices.
